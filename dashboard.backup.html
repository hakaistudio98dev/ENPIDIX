⚙️ Kompresi & Kualitas

Rekaman diambil LANGSUNG dari sumber RTSP (bukan dari frame hasil AI) lewat ffmpeg, supaya hasilnya mulus mengikuti frame rate asli kamera — terpisah total dari beban live-view/AI. Resolusi lebih kecil & CRF lebih besar = file lebih hemat disk.
Tingkat Kompresi (CRF)23
Makin besar = file makin kecil/hemat tapi kualitas gambar sedikit turun. 18-23 kualitas bagus, 24-28 hemat & masih layak buat CCTV.
Durasi per File15 menit
Rekaman terus-menerus, dipotong jadi file baru tiap sekian menit — supaya gampang dicari & tidak jadi 1 file raksasa.
Simpan Selama14 hari
Rekaman lebih tua dari ini otomatis dihapus. Geser ke 0 = simpan selamanya (kelola disk manual).
